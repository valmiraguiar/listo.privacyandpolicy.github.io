# Política de Privacidade do Listo

*Última atualização: 16/11/2026*

Esta Política de Privacidade explica como o aplicativo **Listo** trata as informações do usuário. Ao usar o Aplicativo, você concorda com o que está descrito aqui.

## 1. Quem é responsável pelos dados

O Listo é desenvolvido por **Valarin**. Para dúvidas sobre esta política, entre em contato pelo e-mail **valmiir.aguiar7@gmail.com**.

## 2. Quais dados tratamos

**a) Conteúdo que você cria.** Nomes das listas, produtos, descrições, quantidades, unidades, categorias e o status de "marcado" de cada item. Esses dados são criados por você dentro do Aplicativo.

**b) Preferências do Aplicativo.** Informações guardadas no próprio aparelho para lembrar escolhas de uso.

**c) Dados de uso e técnicos.** O Aplicativo utiliza o **Firebase Analytics**, serviço do Google que coleta dados sobre o uso do app, como eventos de navegação, modelo do aparelho, versão do sistema operacional, idioma, país aproximado e um identificador de instalação.

Não coletamos nome, e-mail, telefone, localização precisa ou outros dados pessoais de identificação para o funcionamento das listas.

## 3. Como os dados são armazenados

As listas e os itens são armazenados **no seu aparelho**, em um banco de dados local. Não enviamos o conteúdo das suas listas para nossos servidores.

Os dados técnicos descritos no item 2(c) são enviados ao Firebase, do Google, conforme a Política de Privacidade do Google, disponível em policies.google.com/privacy.

## 4. Para que usamos os dados

- Criar, exibir, editar, organizar e excluir suas listas e itens;
- Manter as preferências do Aplicativo;
- Entender como o Aplicativo é usado, para corrigir falhas e melhorar a experiência.

Não usamos seus dados de listas para publicidade nem para criar perfis de comportamento.

## 5. Compartilhamento

Não vendemos nem alugamos dados pessoais. Os dados técnicos são compartilhados com o Google, provedor do Firebase Analytics, que os trata em nome do Aplicativo. Não compartilhamos o conteúdo das suas listas com terceiros.

## 6. Backup e exclusão

O Android pode fazer backup automático dos dados do Aplicativo na sua conta Google, conforme as configurações do seu aparelho.

Você pode excluir listas diretamente no Aplicativo. Ao desinstalar o Listo, os dados armazenados no aparelho são removidos, exceto se houver backup na sua conta Google.

## 7. Segurança

Adotamos medidas razoáveis para proteger as informações. Como os dados ficam no seu aparelho, a segurança também depende de você, por exemplo, usando bloqueio de tela e mantendo o sistema atualizado.

## 8. Seus direitos

Conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você pode solicitar a qualquer momento:

- confirmação da existência de tratamento de seus dados;
- acesso, correção e atualização de dados;
- anonimização, bloqueio ou eliminação de dados desnecessários;
- informação sobre compartilhamento;
- revogação do consentimento, quando aplicável.

Para exercer esses direitos, use o contato indicado na seção 1.

## 9. Crianças

O Listo não é direcionado a menores de 14 anos e não coletamos intencionalmente dados de crianças.

## 10. Alterações desta política

Podemos atualizar esta política. Quando isso acontecer, a data no topo do documento será alterada e, em mudanças relevantes, avisaremos no Aplicativo.

## 11. Lei aplicável
